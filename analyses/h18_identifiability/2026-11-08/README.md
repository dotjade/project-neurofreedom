# Synthetic urge/control identifiability

8 November 2026. Start with [report.md](report.md).

This directory contains an artificial two-contribution measurement model, not clinical data or a validated mechanism. The locally frozen plan precedes the numerical run. Repository sources motivate the question but no published effect or reliability value calibrates the inputs.

## Reproduce

Tested environment: Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0. Dependencies are listed in requirements.txt; no additional package was installed for this run.

From this directory:

```sh
python run_analysis.py --output results.json
python independent_checks.py
python -m py_compile run_analysis.py independent_checks.py
python run_analysis.py --output /tmp/h18-identifiability-rerun.json
cmp results.json /tmp/h18-identifiability-rerun.json
```

The run completes 14 measurement scenarios and 6 transfer scenarios, each with 4,000 datasets. The seed, parameter grid, covariance matrices, independent-unit count and stream keys are recorded in results.json. Only aggregate outputs are saved. No real-person data are required or supplied.

Exact byte reproduction is verified for the stated environment. Different NumPy/SciPy/Python versions or numerical platforms may change final floating-point digits; compare substantive outputs and checks rather than assuming a cross-version checksum guarantee.

## Files

- `plan.md`, `plan-freeze.json`: question, predictions, complete planned methods and source hashes recorded before execution.
- `run_analysis.py`, `requirements.txt`: deterministic analysis and dependencies.
- `results.json`: all scenarios, structural rank/equivalence results, aggregate estimates, uncertainty and transfer checks.
- `independent_checks.py`, `independent-check-results.json`: a separately calculated algebra and sampling-distribution check, without importing the simulator. This is not independent authorship or clinical validation.
- `reproducibility.json`: rerun and compilation receipt.
- `report.md`: findings, limitations and next decision.
- `manifest.json`: authored-file hashes, excluding the manifest itself and generated bytecode.

The exercise shows that calibrated, invariant measurements can identify toy-model parameters, while unknown measurement shifts can prevent identification despite excellent apparent precision. It does not establish measurement bias in any actual instrument or infer anyone's mechanism.
