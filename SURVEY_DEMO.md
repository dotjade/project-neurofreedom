# Private survey design preview

Created 8 October 2026 after approval of a private demo with response collection disabled.

Preview: https://neurofreedom-survey-demo.forgotten-stories.chatgpt.site

This owner-private preview contains ten optional structured question blocks across observation coverage, frequency patterns, exams and preparation, physical activity, timing, counterexamples, other changes and everyday interference. The recall period is eight weeks. Recall and timing windows are unvalidated draft choices for clinician and methods review, not an approved questionnaire or clinical scale.

Use imaginary answers only. No real participant information has been collected. The static prototype has no response endpoint, database, connector, form submission, export, free text or upload. Its code uses no networking, analytics or browser persistence. Temporary selections are cleared by Reset or Finish Preview. A fictional example is explicitly labelled as fictional. It computes no clinical score or causal interpretation.

This does not certify anonymous hosting: ordinary access/security logging by the hosting provider must be assessed before any live research service. The page states this limitation. The absence of names would not itself establish anonymity for a future dataset.

Before recruitment: define the question and jurisdiction, obtain appropriate clinical/methods/privacy and institutional research review, assess consent and any child-related requirements, verify data handling and retention, and approve recruitment materials. Neither public sharing nor real response collection has been authorized by this preview's creation.

Source checks verified all ten blocks, referenced local assets, JavaScript syntax, no app response-transmission/persistence APIs, and a content policy that prohibits connections and form actions. A full rendered browser/accessibility audit has not been performed.

The existing private Site should be revised rather than replaced when feedback arrives. No automation refresh or participant-data ingestion is configured.
